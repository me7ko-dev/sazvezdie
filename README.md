# Съзвездие

**Твоите GitHub репота като жива галактика.**

Всяко репо е звезда. Галактиката се ражда пред очите ти — „Големият взрив“
пуска времето от първото ти репо до днес и звездите светват една по една.

- **Ръкав** — езикът (TypeScript, Python, JavaScript…)
- **Разстояние от ядрото** — възрастта: старите са вътре, новите по края
- **Размер** — тежестта (размер, звезди, форкове)
- **Пулс** — колко скоро е пипано. Каквото си пушнал днес, бие като сърце
- **Съзвездия** — репота със общ префикс (`windows20`, `windows20-mobile`…) са свързани с линии
- **Форковете** са по-бледи луни

## Как се ползва

Отвори страницата и въведи потребител, или направо:

```
https://me7ko-dev.github.io/sazvezdie/?u=torvalds
```

- влачи — въртиш галактиката · колелце — приближаваш
- клик върху звезда — детайли и роднините ѝ
- интервал — пусни/спри Големия взрив · времевата линия се влачи
- `⤓` — запазва снимка на твоята вселена
- `?still` — показва направо днешното състояние, без анимация

## Как е направено

Без build, без зависимости: един `index.html`, `style.css` и `app.js`.
3D проекцията е ръчна върху Canvas 2D; данните идват директно от публичния
GitHub API (60 заявки на час без токен).

```
python -m http.server 8765
```
